# 艾飛樂遊戲館

本次新增19款參考經典玩法的艾飛樂風格版本。視覺以立體棋盤、光影與圓潤角色呈現（2.5D），不是Google原版的複製或轉載。
原有三款與新遊戲共用小卡片列表。每款獨立頁面，提供遊戲說明。
爆米花支援同裝置雙人，不含線上即時配對。
冠軍小島為三項時機試煉與探索的原創短篇版本。
方塊工坊提供三關平台跳躍及本機關卡編輯。
