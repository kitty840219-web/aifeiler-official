# 每日一句

## 日期與圖文配對

- 畫面與下載圖片的年份、日期、星期依瀏覽裝置的當地日期計算，不把年份或星期印死在背景圖。
- 平日優先抽取當月、距離當日七天內的圖文，與當天日期完全對應的卡片提高抽中機會。
- 元旦、情人節、平安夜、聖誕節、跨年及 2/29 字卡限定對應日期；對應日的首次每日抽卡優先使用該日字卡。
- 「隨機抽卡」從適合當月的卡片抽選，仍有工作篇與愛情篇；重新開啟保留當天已抽中的結果。
- 同月卡片以不重複袋抽取；優先日期範圍已抽完時，先用尚未抽過的當月卡片。大量手動抽卡耗盡袋子後才會重新循環。
- 素材未補齊的月份，暫用相鄰季節卡片；月份齊全後便不需要此備援。
- 舊版抽到的跨季卡片會在升級時重新配對。已收藏的 ID 與原收藏日期保留。

測試：`npm run test:quotes`。
